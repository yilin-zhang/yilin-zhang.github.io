Decklet

A spaced repetition package for language learners, built on Emacs.

* How it differs

** No card backs to write

You only add the word. When it comes up for review, press l to look it up in any online dictionary.

** Extensible like the rest of Emacs

Decklet has hooks, a public API, and a review buffer made of functions you can replace. For example, decklet-extensions uses them to add a calendar view and Kindle/Kobo import.

* Review keys

1 2 3 4
rate Again, Hard, Good or Easy
l L
look up the word, or choose a dictionary first
n
skip to the next card
u
undo the last rating
H t b
edit the hint, tags or card back
e D
edit or delete the word
q
quit

* Install

Decklet needs Emacs 30.1 or later and the fsrs package from MELPA. Clone the repository:

git clone https://github.com/yilin-zhang/decklet ~/.emacs.d/site-lisp/decklet

Then load it with use-package and set up a dictionary or two:

(use-package fsrs
  :ensure t)

(use-package decklet
  :load-path "~/.emacs.d/site-lisp/decklet"
  :commands (decklet-add-card decklet-add-card-batch
             decklet-review decklet-edit)
  :custom
  (decklet-lookup-providers
   '(("Merriam-Webster" . "https://www.merriam-webster.com/dictionary/%s")
     ("Wiktionary" . "https://en.wiktionary.org/wiki/%s")))
  (decklet-lookup-default-provider "Merriam-Webster"))

Add a word with M-x decklet-add-card and start reviewing with M-x decklet-review. Everything else is in the manual.
