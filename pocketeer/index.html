TUI CLI INSTALL GITHUB ↗

Manage your Analogue Pocket from the terminal.

Keep your ROMs on your computer and sync them to the SD card.

$ cargo install --git https://github.com/yilin-zhang/pocketeer

Get started

  1. 1

    Install

    With Rust installed:

    cargo install --git https://github.com/yilin-zhang/pocketeer
  2. 2

    Import your ROMs

    Platforms are read from the file extensions. By default the library is ~/Pocketeer Library.

    pocketeer library import ~/roms
  3. 3

    Copy games to the card

    Plug in the card. Run this, or press s on a game in the Games tab.

    pocketeer card copy "Metroid Fusion (USA)"
  4. 4

    Back up your saves

    Saves are copied to the library, and older versions are kept. Or press B in the Games tab.

    pocketeer saves backup
