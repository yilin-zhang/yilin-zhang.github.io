◆ POCKETEER
TUI CLI GITHUB ↗

Manage your Analogue Pocket from the terminal.

Keep your ROMs on your computer and sync them to the SD card.

$ cargo install --git https://github.com/yilin-zhang/pocketeer

Your library and the device, side by side.

Install and update cores from the openFPGA inventory.

See which BIOS files your cores are missing.

The device's firmware, free space, cores and games.

CLI

Every TUI action is also a command.

$ pocketeer status
root      /Volumes/POCKET
firmware  2.6 (built 2026-06-16)
space     38.2 GB free of 128.0 GB
cores     4
games     16

$ pocketeer pull save "gba/Fire Emblem (USA, Australia).gba"
gba/Fire Emblem (USA, Australia).gba: save kept

$ pocketeer saves "gba/Metroid Fusion (USA).gba"
VERSION                     SIZE
2026-11-05T23-36-49  32768 bytes  newest
2026-10-29T23-36-49  32768 bytes
2026-10-08T23-36-49  32768 bytes

$ pocketeer push game "gba/Golden Sun (USA, Europe).gba"
